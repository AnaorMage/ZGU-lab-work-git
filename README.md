# Проект: Калькулятор на Python (ZGU-lab-work-git)

## Описание
Данный проект разработан в рамках лабораторной работы по изучению Git и GitHub. Приложение представляет собой консольный скрипт для выполнения базовых арифметических операций.

## Функции
- Вывод приветствия "Hello, World!"
- Функция сложения двух чисел.
- Функция умножения двух чисел (добавлена через разрешение конфликтов).

## Как запустить
1. Клонируйте репозиторий:
   `git clone https://github.com/AnaorMage/ZGU-lab-work-git.git`
2. Перейдите в папку проекта:
   `cd ZGU-lab-work-git`
3. Запустите скрипт:
   `python src/main.py`

## Использованные технологии
* Git
* GitHub (Pull Requests, Releases, Tags)
* Python 3
